# tdd-tictactoe
# Крестики-нолики (TDD)

Простая игра крестики-нолики, разработанная с применением методологии TDD (Test-Driven Development).

## Структура проекта

- `game.py` — логика игры
- `test_game.py` — 15 автоматических тестов

## Как запустить игру

```bash
python game.py
```

## Как запустить тесты

```bash
python -m unittest test_game.py
```

## Итерации TDD

| № | Тест | 
|---|---|
| 1 | Создание игрового поля |
| 2 | Поле из 9 клеток |
| 3 | Поле изначально пустое |
| 4 | Ход игрока X |
| 5 | Нельзя ходить на занятую клетку |
| 6 | Победа по горизонтали |
| 7 | Победа по вертикали |
| 8 | Победа по диагонали |
| 9 | Нет победителя |
| 10 | Ничья |
| 11 | Смена текущего игрока |
| 12 | Смена игрока после хода |
| 13 | Недопустимая позиция |
| 14 | Сброс игры |
| 15 | Подсчёт свободных клеток |
